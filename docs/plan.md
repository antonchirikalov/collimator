# collimator — компилятор pipeline.yaml → Dynamic Workflows

Коллиматор сводит рассеянные лучи в один параллельный пучок: на входе одна декларация, на
выходе — параллельный фан-аут агентов. Линия названий продолжается: spectra → refract →
collimator. Пакет `collimator/`, команда `collimate`.

## Контекст

refract — личный инструмент для подготовки документов (дизайны решений, требования) с
иллюстрациями через figgybanana. За время его разработки Claude Code забрал себе почти всё,
что делает наш движок: параллельный фан-аут, изоляцию контекста, ретраи, структурированный
вывод со схемой, оркестрацию скриптом (Dynamic Workflows), хуки, кастомных подагентов.

Разбор в `docs/analysis-native-claude-vs-refract.md` (там же цифры и ссылки на
документацию) показал: нативно не хватает только трёх вещей — прогона дольше сессии,
человека посреди прогона и гейтов по содержимому. Первое владелец согласился считать
допустимой потерей, второе закрывается разбиением на стадии, третье — нашим же скриптом
проверок.

Решение: **движок не нужен, нужен компилятор**. `pipeline.yaml` остаётся единственным
источником правды, из него генерируются скрипт воркфлоу и определения подагентов. Модель
скрипты не пишет — их пишет наш генератор, поэтому состав и число агентов заданы YAML, а
сгенерированный скрипт коммитится и диффится.

Ключевой факт про Agent SDK, снимающий альтернативу: SDK требует авторизации ключом API
(«сторонним разработчикам не разрешено использовать вход через claude.ai или лимиты
подписки для их продуктов, включая агентов на Claude Agent SDK»), а Dynamic Workflows
исполняются внутри Claude Code на уже имеющейся корпоративной подписке. Ключ не нужен.

Отдельно решено: **новый репозиторий**, refract замораживается как источник промптов,
типов, шаблонов и валидатора. Причина не в объёме кода (хотя умирает 78% движка и 76%
тестов), а в документах: `CLAUDE.md` объявляет `SPEC.md` источником правды, а это 1277
строк про исполнение — планировщик, леджер, восстановление. От инвариантов I1–I10
переживают полтора.

  ```
    validated  explainer_article.yaml  (0 errors)
  ```

Гарантии, которые переезжают из движка в генератор: валидация до генерации (не

петли невозможен, потому что генератор его не эмитит).

## Риски

- **`mcpServers` у агента внутри воркфлоу.** Для коллег в командах этот фронтматтер явно
  игнорируется; про агентов воркфлоу прямого утверждения в документации нет. Этап 0 нужен
  ровно поэтому.
- **Потеря прогона при выходе из сессии** принята как допустимая. Смягчение: короткие
  сегменты и много мелких агентов вместо одного длинного — при возобновлении кэш обрывается
  на первом незавершённом агенте, и всё, что стартовало после, считается заново.
- **Окружение внешнего CLI.** `PAPERBANANA_BIN` и три `SS_GATEWAY_*` живут в
  `.claude/settings.local.json` — файл в `.gitignore`, машинные пути и UUID профиля в историю
  не попадают. К ним добавились `KIMI_BASE_URL`, `GUIDELINES_PATH` и `REFERENCE_SET_PATH`:
  figgybanana разрешает свои пути к данным от текущего каталога, а мы зовём его из чужого, и
  без абсолютных путей корпус эталонов молча не используется.
- **Компилятор может оказаться избыточным** для семи шаблонов личного инструмента. Решение
  принимается после этапа 0: если руками написанный сегмент читается лучше сгенерированного,
  честнее оставить рукописные скрипты и не тащить 2470 строк валидатора.
- ~~**Расширение файла воркфлоу.**~~ Снят **дважды, и второй раз правильно**: сначала решили,
  что лечится обёрткой, потом проверили — дело именно в расширении. `.claude/workflows/*.js`
  становится командой сам, `.mjs` не сканируется. Обёртки не нужны.
- ~~**Передача `args` слэш-командой.**~~ Снят: обёртка подставляет `$ARGUMENTS[0]` в объект
  `args`, свободный текст в разборе модели больше не участвует.
- ~~**Хук `SubagentStop` — непроверенное допущение.**~~ **Проверено 2026-08-14, допущение не
  подтвердилось.** Хук на агентов воркфлоу срабатывает, и payload несёт всё нужное для
  ветвления (`agent_type`, `agent_id`, `agent_transcript_path`, `stop_hook_active`) — то есть
  оба опасения плана, применимость и вечная блокировка, снимались бы им же. Но **код возврата
  2 игнорируется**: агент, заявивший несуществующий файл, спокойно завершился. Значит хук —
  детектор и протокол за ноль токенов, а принуждение остаётся стадией в скрипте. Реализация:
  `tools/gate_hook.py`.
- **Порог гейта, который нельзя нарушить.** На первом прогоне пробника гейт прошёл сразу, и
  петля ретрая осталась бы непроверенной — порог пришлось поднимать вручную. `collimate build`
  обязан предупреждать, если порог заведомо выполним первым черновиком: иначе целая ветка
  конвейера ни разу не исполняется, а выглядит рабочей.
- **Форма команды в шелле не воспроизводится.** Одна и та же строка уходила то в `Bash` с
  переписанным путём `/c/Users/…`, то в `PowerShell` с префиксом `cd …;`. Разрешения
  печатать для обоих; `gate.py` нормализует msys-путь сам, потому что через PowerShell такой
  путь до Python не доживёт (в git-bash он переписывается автоматически — проверено).
- **`settings.json` в git.** В нём машинные пути и UUID профиля шлюза. Для локального
  личного репозитория нормально; при появлении публичного ремоута блок `env` переносится в
  `.claude/settings.local.json` и уходит в `.gitignore`.

`~/Documents/agents/collimator/` — отдельный репозиторий, `refract-claude` не трогаем.

```
collimator/
  collimator/

    cli.py              ← новый: collimate build …
  library/              ← из refract целиком: 22 агента, типы, 7 шаблонов
  tools/gate.py         ← из этапа 0
```

рантайму, которого нет. Переживают I5 (инструкции из контракта — теперь работа генератора) и
